# 我的个人博客

## 发布一篇文章

1. 打开 `_drafts/文章模板.md`，复制全部内容。
2. 在 `_posts` 文件夹新建文件，例如 `2024-05-20-my-first-post.md`。
3. 粘贴模板，修改标题、日期、分类和正文。
4. 点击 GitHub 的 **Commit changes**。稍等一两分钟，网站会自动更新。

分类填写：博客用 `blog`，幻灯片用 `slides`，生活用 `life`。

`date` 可以填写任意过去时间，例如 `2023-01-08 20:30:00 +0800`。列表会按这个时间从新到旧排列。

本地检查内容格式：`ruby scripts/check_content.rb`
